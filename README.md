# Reverse-Engineering Non-Stationarity

This project examines **multi-armed bandit learning in non-stationary environments**, where the reward probabilities of two arms change over time. It considers **Explore-then-Exploit (EtE)**, **Upper Confidence Bound (UCB)**, and **Multiplicative Weights (MW)** under different reward-change scenarios.

The goal is to investigate how exploration strategies and reliance on past observations affect an algorithm's ability to adapt when the best arm changes.
